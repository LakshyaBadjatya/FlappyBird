# 🐦 Flappy Bird (Unity)

A simple **Flappy Bird–style 2D game** built using **Unity**. This project was created to practice game development fundamentals like physics, collision detection, scoring, and Android builds.

---

## 🎮 Game Overview

* Tap / click to make the bird fly upward
* Avoid obstacles (pipes)
* Score increases as you pass obstacles
* Game ends on collision

---

## 🛠️ Built With

* **Unity** (2D)
* **C#** scripting
* Android build support

---

## 📁 Project Structure

```
Assets/          → Game scripts, sprites, scenes
Packages/        → Unity package dependencies
ProjectSettings/ → Unity configuration files
```

---

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/LakshyaBadjatya/FlappyBird.git
```

2. Open **Unity Hub**
3. Click **Open Project** and select the cloned folder
4. Open the main scene from `Assets/`
5. Press **Play ▶️** in Unity

---

## 📱 Android Build (Optional)

* Target API: Automatic (highest installed)
* Scripting Backend: IL2CPP
